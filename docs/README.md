# Meal App Shared Docs

Shared product/backend documentation for the meal planning app.

Use this directory as the source of truth for both frontend and backend sessions.

## Start here

1. `CONTEXT.md` — canonical domain language/glossary.
2. `docs/PRD_BACKEND.md` — consolidated backend MVP contract.
3. `docs/BACKEND_HANDOFF.md` — handoff for backend repo/session.
4. `docs/IMPLEMENTATION_SLICES.md` — ordered vertical slices with stories and tasks.
5. `docs/PRD_APP.md` — app-wide product decisions.
6. Feature PRDs:
   - `docs/PRD_AI_PLANNER.md`
   - `docs/PRD_RECIPE_EXPERIENCE.md`
   - `docs/PRD_INVENTORY_SHOPPING.md`

## Workflow rule

If a contract/product decision changes, update this shared docs folder first, then update frontend/backend implementations.
